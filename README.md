Miniapp móvil de 15 días.

## Publicar con GitHub Pages
1. Crea un repositorio (por ejemplo `mi-plan-alimentacion`).
2. Sube `index.html` a la raíz de la rama `main`.
3. En GitHub abre Settings > Pages.
4. En Build and deployment selecciona Deploy from a branch.
5. Selecciona `main` y `/ (root)`, y guarda.
6. GitHub mostrará la URL pública cuando termine el despliegue.

Las casillas marcadas se guardan localmente en el navegador del dispositivo.
